🔬 Dataset & Code

😴 REST Dataset

Elite Female Football Athletes Dataset and Analysis Tools

17 days of wrist actigraphy, well-being questionnaires, caffeine consumption, screen time and daily hand-strength tests from 21 elite female football athletes. The repository contains sleep detection algorithms, preprocessing scripts, technical validation, and transfer-learning inference with an LSTM trained on MESA.
