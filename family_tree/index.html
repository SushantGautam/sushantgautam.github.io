How to edit

Replace family_tree/sample.ged with your real GEDCOM export from Gramps, MyHeritage, WikiTree, FamilySearch-compatible tools, etc.

  • Use GEDCOM for the data.
  • Use Topola Viewer for pan/zoom, focus, details, export, and large-tree browsing.
  • This page loads the GEDCOM from your GitHub Pages URL, so no backend is needed.

After replacing the file, refresh this page. If GitHub Pages cache is slow, hard-refresh.
